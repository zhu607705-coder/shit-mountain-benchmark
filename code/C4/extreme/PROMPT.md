# C4：同一个缓存，三个发布时代，最后谁的产物才是真的

**完整 extreme 资格必须同时通过 [stage-v2可变manifest一致cut协议](STAGE_PROTOCOL.md)。** 新接口明确允许build期间sources/env发生更新，要求一致旧版本/新版本或显式重试；提供单机制通过、组合混合版本失败的真实文件starter。下文旧Builder接口的单次源稳定约束继续有效。

继续使用统一 C4 的 `Builder(root, cache).build(spec, target, env) -> bytes` 和原 DSL；允许重写缓存与执行计划。source 内容在一次 build 内保持稳定，变化发生在两次构建之间；不偷偷追加“任意并发文件修改下原子快照”的不可能要求。

本版 full 是 **20 个项目根目录、1,000 个历史变更、5,000 节点/2,200 深度 DAG、12 个发布进程**。原公开 workload 为两根目录共缓存、100 次变更，前两项各 10 倍。5,000 节点原来只写在未执行设想里，现在生成并实际交给候选与独立解释器，不能声称是“旧已执行 5,000 再乘十”。

## 跨阶段事故链

多个项目有同名源文件、不同内容，却共用缓存。构建一次后改变源字节，同时恢复原 mtime，长度保持不变；下一阶段改变环境绑定，某些节点会重复引用同一个环境变量。接着调整 deps 顺序，使集合相同而语义不同。需要把输入内容、根目录边界、配方、按序依赖和明确环境语义带到正确的缓存键中。

删除某个已缓存源文件，让一次构建失败，再恢复文件并重新构建。失败不能被旧缓存伪装成成功，也不能污染后续重试。残留不完整缓存文件需要重建，而不是从部分内容返回“命中”。

12 个独立进程同时向共享缓存发布，混合来自不同 root 与 env 的结果。全部旧构建结束后进入新的源/环境 epoch，所有项目再构建一次。旧发布完成并不授权新 epoch 复用旧结果；“文件写入原子”与“缓存内容身份正确”是两个需要同时满足的条件。

最后对含长链和共享分支的 5,000 节点 DAG 求值，产物只有 64 字节散列。递归栈溢出属于规模边界，不把它单独包装成推理深度证据。真正的修复还必须贯穿缓存历史与发布生命周期。

## 合约与可变部分

保留 `../TASK.md` 的 DSL、Unicode、依赖顺序、只访问可达图、root 路径边界、缺文件与循环错误契约。source/path 不存在必须给出 BuildError；不同类型的合法缓存实现均可，只要最终字节等于无缓存解释结果。允许数据布局、结构共享、调度、缓存格式和增量失效策略自由选择。

公开不完整缓存实验会截断裁判临时目录中候选生成的少量普通文件，不触碰源码或源目录。缓存是可重建数据，恢复后应能从合法源重新得到正确结果。未经声明的 env 不进入语义。禁止读裁判 oracle 或硬编码 seed。

## 运行与证明

```bash
python3 code/extreme.py --task C4 --scale smoke --seed 260926 --output c4.json
python3 code/extreme.py --task C4 --scale full --seed 260926 --submission my_builder --output c4-full.json
python3 code/extreme.py --task C4 --scale full --export /tmp/c4-public
```

目录需包含 engine.py 或 baseline.py 并导出 Builder 和 BuildError。导出包包含原 starter、实际场景、无答案的观察型smoke和说明。smoke 保留历史链/并发链和深图，规模为 2 root、8 变更、3 个发布进程及 1,200 节点；full 才执行上述全量。

独立迭代解释器不读缓存、不导入候选，用显式源字节计算结果；微型环境重复引用例能手算输出 `!z11`。候选需提交定位记录、修改前后证据、自测与原回归。原基线如果通过历史链，会如实报告；只要深图失败就仍未通过扩大后的完整条件。

## 评分

v0.2 机器合约质量 **Q = 100，当且仅当全部旧接口扩大检查与必需 stage-v2 通过；否则 Q = 0**，写入 `raw_score` 和 `quality_score`。过期输出、跨 root 串用、错误依赖顺序、删除后伪命中、混合 manifest 或接口缺失均是门槛失败；`machine_pass_rate` 只作诊断。

独立 host 的 Codex 评分流程使用 Agent 耗时和 token 记录区分不同正确实现；裁判执行时间和缓存 I/O 时间不是模型思考时间，也不启用未标定的冷/热构建或内存 bonus。正式比较使用冻结 full 轮次，smoke Q 仅表示调试子集。未来封存集须采用相同已公开契约。本地执行器不是安全沙箱。
