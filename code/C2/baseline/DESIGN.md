# C2 基线说明

每个 Engine 独立拥有定义和缓存。缓存仅记录某节点最近一次成功结果，值为不可变 tuple。每次 set 更新节点版本；缓存签名包含该节点版本及有序依赖的结果版本。依赖版本变动会沿本次 DFS 自然传播，不依赖容易失效的反向边索引。

每次 build 都访问当前依赖图和别名，因此拓扑环、缺节点、取消与错误顺序不会被历史命中遮住。DFS 当前路径集合只用来识别真正的环，本次 memo 复用共享 DAG 节点；finally 清理活动路径。失败节点不写缓存。返回时复制成独立 list，外部调用者不能修改缓存。

一次构建会花 O(V_reachable + E_reachable + alias-resolution + changed-operator-work + output-size)。别名未做版本缓存，所以长链多次出现时仍有优化空间。节点定义等价替换会提高版本并触发不必要的重算，内容等价缓存也可改进。空间包含当前定义、每个节点最多一个成功向量及一次构建的 DFS/memo。旧定义的最后一次成功值在新失败时可能继续占用缓存，但不能被错误复用；删除节点会释放其直接缓存。

本方案重视易审查的不变量。它仍遍历完整可达图；更先进的取消检查、反向依赖传播及别名失效算法可能更快，必须维持完全相同的可观察错误语义。
