# C2 核心图引擎兼容契约

你接手一个把数据处理任务编排成图的内部构建引擎。它为加速重复构建加入了缓存，又陆续支持别名、动态改图和取消。现在偶发地返回旧结果，取消后重试仍为空，某个项目还会读到另一个项目的缓存。表面补一个 `clear()` 可以消除部分问题，但会丢掉增量构建的价值。

**任务：修复 `repository/buggy/app/core/`，使状态变化、错误、取消和可变返回值的组合符合合约，并在重复构建及少量分支变更的负载上降低时间和内存。** 算法可自由选择：版本戳、反向依赖、内容地址缓存、结构共享或其他方案均可。不预设唯一补丁和最优架构。

## 接口与状态

提交 `engine.py`，导出：

```python
class Engine:
    def __init__(self, nodes: dict, aliases: dict): ...
    def step(self, command: dict) -> dict: ...
```

每个 `Engine` 有独立状态；构造参数和 `set` 参数归调用方所有，引擎应保存自己的定义。构建成功必须返回可由调用方任意修改的独立列表，后续构建不能受其修改影响。多次构建允许复用内部不可变值。

输入保证结构合法、名字为非空字符串、数值为整数而非布尔值。最多 500 个节点/别名、1,200 条命令、依赖路径深度不超过 200、每个输入向量最多 4,096 个整数、每个可成功计算的节点输出最多 500,000 个整数。节点可以形成环、缺依赖或含未知操作。金额/溢出语义不适用，算术使用任意精度整数。

`step` 支持五种命令：

| command | 语义 | 返回 |
|---|---|---|
| `{"op":"set","name":n,"node":definition}` | 新增或完整替换节点定义 | `{"ok":true}` |
| `{"op":"delete","name":n}` | 删除节点；不存在时无操作；别名保留 | `{"ok":true}` |
| `{"op":"alias","name":a,"target":n}` | 新增或替换别名 | `{"ok":true}` |
| `{"op":"unalias","name":a}` | 删除别名；不存在时无操作 | `{"ok":true}` |
| `{"op":"build","target":n,"cancel_at":[...]}` | 按当前图构建，`cancel_at` 可省略 | `{"value":[...]}` 或 `{"error":"CODE"}` |

别名解析递归进行。别名优先于同名节点；`set` 不自动删除同名别名。别名环报 `ALIAS_CYCLE`，最终指向不存在的节点报 `MISSING`。取消列表按**解析后的真实节点名**匹配。

## 冻结的执行合约

构建的可观察语义是：按节点 `deps` 列表从左到右、深度优先求值；所有依赖成功后，检查当前真实节点是否在 `cancel_at`，再执行操作。未提供 `deps` 等价于空列表，`input` 自身也必须先遍历它的依赖。

节点定义的 `op` 决定向量运算：

| op | 定义 |
|---|---|
| `input` | 返回 `data` 指定的向量，忽略依赖的数值，但仍遍历依赖 |
| `concat` | 依次拼接全部依赖向量，保留顺序和重复依赖 |
| `sum` | 按位置求和，以最长依赖长度为准，短向量补零 |
| `sort` | 拼接全部依赖后按整数升序排序，保留重复值 |
| `unique` | 拼接全部依赖后去重，按整数升序排列 |
| `scale` | 拼接全部依赖，再逐个乘以节点整数 `factor` |
| `fail` | 依赖成功且未取消后，报 `FAILED` |
| 其他字符串 | 依赖成功且未取消后，报 `OP` |

上述非 `input` 运算在零依赖时得到空列表（`fail` 和未知操作仍报错）。`input` 的 `data`、`scale` 的 `factor` 保证存在且类型正确。额外字段无语义，但完整 `set` 可替换任何定义。

访问当前依赖路径上的节点报 `CYCLE`；共享 DAG 节点、重复依赖不是环。错误按上述从左到右的求值顺序取第一个。命中取消名单报 `CANCELLED`，即使已经存在缓存也必须遵守本次取消语义。失败/取消不改变图定义；此前已成功计算的纯结果可保留，只要后续结果仍符合当前图。不得将失败或取消伪装成成功的空列表。

公共 harness 使用 `tamper_last` 来模拟调用者把最近一个成功返回列表原地改成单元素列表；这不是 `Engine.step` 命令，参赛者不需要实现。修改后再次构建必须仍得到真实结果。
