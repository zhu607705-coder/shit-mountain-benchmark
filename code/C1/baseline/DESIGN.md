# C1 基线说明

先完整扫描身份，保存第一个规范载荷并把多版本身份加入冲突集合；冲突身份永远不能贡献分录或撤销。再独立验证唯一载荷，先解析所有有效撤销，最后只投影没有被撤销的合法 post。所有金额使用整数。

这保持三条不变量：一个身份至多贡献一次；冲突/非法事件贡献为零；撤销仅影响同租户的合法 post。集合式撤销消除了重复扣减与先后顺序影响。

若 N 为事件数、B 为输入编码总长度、K 为唯一身份数、A 为出现的账户数，规范化开销取决于每个对象的字段排序，本题每个有效事件字段数固定；总工作约为 O(B + K log K + A log A)，额外空间 O(B_unique + K + A)。输入与规范字符串同时保留，仍存在明显内存优化空间。可以改用不丢失 JSON 类型信息的结构化标识、减少临时串和峰值分配，但必须处理冲突及布尔/整数/浮点边界。

这个实现是可运行基线，不是唯一参考结构，也不证明最优。
