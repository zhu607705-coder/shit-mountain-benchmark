# 用统一启动器比赛

在仓库根目录运行 `python3 scripts/launch_arena.py`，或在 macOS 双击 `启动挑战赛.command`。只需要本机 Python 3.10+；完整题库检验还需要 Node.js 22+。无需安装 npm/pip 依赖。

## 一场比赛

1. 选择题池和青铜、白银、黄金、钻石、王者、噩梦中的一个档位，点击“抽一道”。题池可限定推理/代码/前端；服务器随机选中实际题目后，卡片才揭晓。
2. 点击“开始这题”，打开任务 README 或下载公开题包，把它交给答题 Agent。三段任务分别是复现与定位、目标机制实现、范围内完整验证，各有材料、交付物和预算。
3. Agent 在自己的可写工作目录完成答案，保存复现、自测和未解决问题。每个参赛者使用独立会话与工作副本。
4. 填写模型/选手名称、本机答案路径和入口，点击“封存并检验”。答案是实际文件或 ZIP；单文件入口为文件名，代码仓库入口通常是 `.`，前端使用题面规定的适配器入口。
5. 等待检验结束。继续向同一场添加其他模型的答案，即可比较同一抽签实例上的结果。

同场后加入的选手不会重新抽签。正式比赛应在所有模型完成答题前隔离彼此的答案和结果，避免后参加者利用前面的失败报告；本地界面本身不提供参赛者账户或访问隔离。重复试验请新开一场或使用 [批量实验](../experiments/README.md) 的多模型 cohort。

需要指定题目时使用次级选题入口。随机请求使用 `task_id=random` 和 `track=all|R|C|F`；服务器保存真实选中的 task_id、题池和选题方式，导出与判分使用同一个实际任务。鼠标切面和洗牌动效不决定抽签结果。触屏或减少动态效果偏好使用稳定构图。

## 怎样读结果

- **R 推理题：**“合法完成”表示按协议完成了评估；质量由实际损失决定，低质量策略也可能合法。
- **C 代码题：**完整通过所选检查才显示完成；普通失败可保留部分分，公开基础约束失败为 0。
- **F 前端题：**自动分是语义检查分，完整浏览器体验与视觉仍需实际评阅。
- **相对分：**同场最高正原始分为 100，其他选手按比例计分。唯一参赛者得到 100 不表示最优解，全部为 0 时没有冠军。
- **效率分：**先看答案质量，再按提前冻结的预算计算扣分；未知或未经核验的时间/token 不参与正式效率榜。

本次正式判分采用封存答案第一次真正完成的裁判结果。后续重新检验只追加诊断记录；运行环境出错、取消或未完成时可以重试，不把它们伪装成候选质量零分。文件、抽签规则或裁判源码被修改后，旧场次的检验会被拒绝，需要新建场次。

## 交给 Codex 复核

点击“下载评阅任务”，把生成的 `GRADING_REQUEST.md` 交给独立评分的 Codex。它包含当前场次、封存答案、机器结果和绑定信息；下载文件本身不会启动模型，也不是完成评分。

Codex 应实际查看适用的 UI、功能与证据，并核验整个答题过程的宿主日志/API usage，包括全部调用、重试和工具操作。真实思考时间不可见时保持 null。机器裁判的运行时间只表示检验成本。

核验后，Codex 按评分任务里的绑定模板生成 `review.json`，由主办方导入：

```bash
python3 scripts/launch_arena.py --import-review /absolute/path/review.json
```

此入口检查场次、答案封存、正式质量结果、效率策略以及独立证据文件的哈希。选手提交的 `source: API` 等标签不会自动取得信任。导入后刷新页面查看效率分；这一步不会自动把前端视觉待评改成通过。

## 记录位置与接口

`reports/arena/matches/<match-id>/` 保存公共题包、已封存答案和组织者私有报告，默认被 Git 忽略。不要把该目录作为公开仓库内容分发。公开题包可以下载或复制到独立的可写目录；不要修改启动器保存的只读原件。

自动化宿主可使用本地 JSON 接口：`GET /api/bootstrap`、`POST /api/draw`、`POST /api/matches/<id>/submit`、`POST /api/matches/<id>/grade`、`GET /api/matches/<id>/status` 和 `GET /api/matches/<id>/leaderboard`。修改请求须带 bootstrap 返回的 `X-Arena-CSRF`；外部站点不能直接发起修改。指标的可信复核只能经主办方 CLI 导入。

题目适配器仍通过独立子进程运行真实裁判。当前工作流面向可信本机实验，外部陌生提交需由组织者在独立执行环境中运行；目录权限不构成操作系统沙箱。
