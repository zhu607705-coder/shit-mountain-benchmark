# R2：传感器互相打架时，下一步测什么？——风险与成本约束下的主动诊断树

## 任务

一个完全虚构的工业装置可能处于 8 类潜在故障。你可选用 18 项实验，最后在 11 种干预中选一种。实验会占用成本、造成延迟，有些实验本身还有副作用；部分实验互相排斥或必须先完成前置实验。便宜传感器还可能受到同一通道故障影响，反复给出彼此一致但错误的信号。

你要提交一棵自适应决策树：先做哪个实验，看到不同结果后如何继续，什么时候停止，最后采取什么干预。目标是同时降低平均损失、较坏尾部损失与实验费用。

这是**合成工业系统的策略优化题**，不是现实医学诊断，也不是要求猜一个标准故障标签。输入完整公开了 180 个有限潜在世界的结果与损失表；并没有对参赛者隐藏这些世界的真值。优化对象是所有这些世界共同执行的一棵低成本策略树，最优树不预设。

## 输入与信息边界

`input.json` 包括：

- `tests`：18 项实验的 ID、可能结果、成本、延迟、前置实验、互斥组和生成模型元数据。
- `actions`：11 种终止干预，包括 8 种局部修复、2 种广域修复及停机隔离。
- `worlds`：180 个公开潜在世界；每个世界含权重、潜在类别、罕见事件标记、所有实验结果、逐项实验副作用、单位延迟损失、各干预损失。
- `constraints`：最多 364 个树节点，每条路径至多 7 次实验，总实验成本至多 24。

你在**构造树时**可以使用整个公开输入，包括潜在类别和干预损失。裁判在**执行树时**只通过已经选择的实验结果沿分支前进；树节点不能读取世界 ID、潜在类别、罕见事件标记或未实施实验的结果。因此即使你知道所有训练世界，也仍然要把这种知识压缩成满足路径预算的一套实验与干预策略。

实验结果固定为字符串 `"0"`、`"1"`、`"2"`，含义由该实验的合成结果表决定，不存在“多数传感器投票必然正确”的规则。世界在一次回放中保持不变，实验结果不随顺序改变；测试只改变已知信息，并累加成本、延迟与副作用。只有叶节点的干预计入终止干预损失。

## 提交协议

UTF-8 JSON 文件顶层只允许 `format_version` 与 `tree`：

```json
{
  "format_version": 1,
  "tree": {
    "test": "T00",
    "branches": {
      "0": {"action": "A08"},
      "1": {"action": "A09"},
      "2": {"action": "A10"}
    }
  }
}
```

这是一棵可行但质量不保证的示意树。每个节点只能是：

- 实验节点：且仅含 `test` 字符串与 `branches` 对象。
- 终止节点：且仅含 `action` 字符串。

硬约束：

1. 所有实验和干预 ID 必须存在。
2. 实验节点必须为该实验的**全部且仅有的**结果提供分支，包含公开世界里暂未出现的结果。
3. 同一条路径不能重复同一实验；每个前置实验必须先在该路径上出现。
4. 同一条路径不能执行两个具有相同非空 `exclusive_group` 的实验。
5. 每条路径至多 7 个实验、成本和至多 24；整棵树包括叶节点至多 364 个节点。即使某条路径没有任何公开世界会走到，也必须满足约束。
6. `format_version` 必须为整数 1。额外字段、重复 JSON 键、NaN、Infinity 等非法输入被拒绝。

不同分支可以使用同一种实验。为了保持格式简单，提交采用内嵌树，不接受节点引用、任意代码、循环或共享节点图。

## 回放和评分

裁判对每个世界从根节点执行。实验节点读取该世界中该实验的结果并进入对应分支，直到叶节点。世界总损失为：

`loss = 终止干预损失 + 已实施实验副作用之和 + 实验延迟之和 × 该世界单位延迟损失`

实验成本单独计价，避免与副作用混为一项。

- `L`：加权平均 `loss`。
- `R`：损失最大的 10% 世界概率质量的平均损失，即上尾 CVaR；边界权重允许按比例截取。
- `C`：加权平均实验成本。
- `objective = L + 0.45R + 0.30C`，越小越好。
- `raw_score = 1000 / (1 + objective/35)`，越大越好。

合法树返回 `valid=true`、`feasible=true` 和分项。非法树返回二者为 false 且原始分为 0；较高损失属于合法策略的低分表现。赛会归一化单独进行，不能把本题自带基线认定为最优或直接记为满分。

```bash
python3 judge.py --input input.json --submission your_output.json
```

输出含每个世界经过的路径、最终干预、成本、延迟损失、副作用和总损失，可逐项复核。

## 为什么困难

最廉价的分辨实验未必最能降低决策损失；高信息量实验可能造成过多延迟；平均损失低的策略也可能把少量罕见严重世界推入很差的结局；前置实验可能眼下没有价值，却打开更有价值的后续实验。更重要的是，整体 CVaR 不能简单等同于每个分支 CVaR 的加权平均，所以朴素贪心树只是一种近似解。

可选附交不超过 800 字的方法说明，但得分仅由策略 JSON 的实际回放决定。类别预测准确率不是本题评分目标。
