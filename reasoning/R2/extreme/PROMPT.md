# R2：检查本身会改变系统的主动诊断

这是统一 R2 的 `extreme` 规格。full 执行 **1,800 个潜在世界、180 项可选实验**，旧实例为 180 个世界和 18 项实验，两项实际计数均为 10 倍。smoke 执行相同机制的 24 个世界。所有故障、损失和实验均为合成定义，不是医疗或真实工业决策规则。

你逐次选实验，观察结果，最终选择干预。每个世界的故障、通道漂移和测量噪声不公开；实验机制与先验完整公开。实验改变应激水平，准备工序会永久锁定可用腔室，因此后来的同类读数不一定还能使用先前的解释方式。

## 公开模型与隐藏变量

第一次观测的 `model`（导出包也提供 `public.json`）给出 180 项实验、成本与依赖、先验及参数。后续观测不重复发送模型，策略应保存它。每个场景的 `cohort` 为 0–3，已知所属群体，但不知道故障。

- 故障 `f` 是 0–31 中一个整数。群体 `c` 中，`floor(f/8)=c` 的各故障先验为 3/48，其余各为 1/48。
- 四个潜在漂移位相互独立，群体 0/1/2/3 的每位概率分别为 0.08/0.16/0.24/0.32。多个实验共享漂移通道，因此误差相关。
- 5 个 screen 实验检测故障的五个二进制位，通道为 `bit mod 4`。读数 = `故障位 XOR 通道漂移位 XOR (当前stress mod 2)`。
- 4 个 calibrate 实验读取 `通道漂移位 XOR (当前stress mod 2)`，随后将 stress 加 1。它们不直接报告故障。校准结果没有额外测量噪声。
- 4 个 prepare 实验选择腔室 0–3，读数恒为 0；选择不可撤回，不能在同一场景再次准备任何腔室。stress 增量为 `chamber mod 2`。
- 167 个不同 assay 按公开 `targets/channel/chamber/threshold/cost/stress_delta/toxicity/delay` 定义，只有准备了对应腔室才能执行。其读数 = `1[f属于targets] XOR 通道漂移位 XOR 1[当前stress≥threshold]`。
- 每个 screen/assay 的理想结果再以 0.04 概率翻转，随机数按世界与实验 ID 固定，不因策略顺序改抽。不同实验的额外翻转独立，通道漂移仍共享。
- assay 的副作用为 `toxicity×(1+2×1[f属于targets])`；其他实验副作用为 0。副作用真实值不会在诊断途中泄露，避免从损失反推真值。
- 先按当前 stress 产生结果，再增加该实验的 stress_delta。每次实验的公开延迟、成本累加。

总实验预算 16，每场最多 12 次实验；同一实验不允许重复。该限制避免通过重复测量重新抽取噪声。

## 动作与接口

提交持续运行的 Python NDJSON 程序：stdin 一行 JSON 观测对应 stdout 一行 JSON 动作，立即 flush。`reset=true` 为新世界，不可把上一世界的后验当成当前世界真值。观测包含 `task/reset/episode/cohort/history/remaining_budget/stress/prepared_chamber/max_queries`，首轮还包含 `model`。历史项为 `test/result/stress_before`。

动作只能有一个字段：

```json
{"test": 5}
```

或终止：

```json
{"action": 36}
```

实验索引 0–179。干预 0–31 为针对该故障的精确修复，32–35 为对应 8 类故障组的广域修复，36 为停机。

设最终应激为 `s`：

- 精确修复命中：损失 `s`；误修但同组：`62+3s`；误修且不同组：`105+3s`。
- 广域修复命中组：`20+2s`；未命中组：`100+2s`。
- 停机：`73+0.4s`。

动作必须是普通 JSON 对象；整数索引不接受布尔值或浮点数。额外字段、重复键、NaN、超预算、重复实验、缺少准备、互斥准备和不终止均判非法；任一世界非法则整次提交无排名资格。数据以值快照传递，但本地执行不是恶意代码安全沙箱。

```bash
python3 reasoning/extreme.py --task R2 --scale full --submission /absolute/path/policy.py --output result.json
python3 reasoning/extreme.py --task R2 --scale full --export /tmp/R2-workspace
```

也支持只含 `{"action": {"action": 36}}` 的 JSON 文件，表示始终停机的常量对照。默认单次响应 2 秒、全部决策 120 秒；正式赛须预先固定统一资源预算。

## 分数与策略难点

每世界 `loss = 干预损失 + 实验副作用 + 0.6×延迟 + 0.3×实验费用`。`objective = 0.7×平均loss + 0.3×最高10%概率质量平均loss`。`raw_score = 100/(1+objective/50)`；较高更好。最终比赛分按同轮有效最高 raw_score 归一化为 100。不同群体的平均损失也输出，便于复核尾部是否来自机制漂移。

准备本身没有信息，却打开后续 assay；校准能降低读数混淆，却会改变 stress、后续实验解释以及最终干预风险。只按即时信息增益、只选最便宜检查或只优化平均损失都可能给出不同且欠佳的行为。

独立两世界见证中，直接干预的平均损失为 31；先做无信息的准备，再做合法 assay，并据结果干预，损失为 0.6。自测同时用实际裁判和独立公式验证这个差异。作者基线采用预先固定的校准＋五位筛查顺序，终止时枚举 512 个故障/漂移假设计算精确后验和最小期望干预损失；它没有搜索腔室准备和 assay 的条件策略。

公开固定种子是可复现演示，不是隐藏测评。正式世界应在策略冻结后随机生成、封存并在赛后披露；导出包只给公开模型，不给世界真值、未来结果或生成种子。未开展多模型难度标定，也不宣称作者参考策略是最优。
