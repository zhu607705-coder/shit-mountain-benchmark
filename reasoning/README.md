# 推理赛道 R1–R4

四道题共用质量分、相对分与合法性记录。前两题交决策JSON，后两题交可执行策略；输出协议不同是任务本身的需要，不另设来源分组。

| 题号 | 任务 | 公开输入与提交 |
|---|---|---|
| [R1](R1/PROMPT.md) | 相关扰动下的鲁棒资源调度 | input.json → 任务选择、模式与优先级JSON |
| [R2](R2/PROMPT.md) | 风险与成本约束下主动诊断树 | input.json → 有前置/互斥/预算约束的树JSON |
| [R3](R3/PROMPT.md) | 有限探针下的检查与修复决策 | 模型与已观测历史 → 策略act() |
| [R4](R4/PROMPT.md) | 任务到达与设备故障下在线调度 | 当前可见观测 → 分配策略act() |

每题的 PROMPT.md 是公开合约，baseline 是参考实现而非唯一答案。R1/R2 的裁判直接检查JSON；R3/R4的本地裁判导入可信策略，输入引用被隔离，但它仍不是安全沙箱。

从仓库根目录运行 `python3 run_baselines.py` 可统一重跑基线。参赛工作区通过 `python3 integrations/cli.py export-task --task R3 --output workspaces/R3` 等命令导出，不含参考策略和组织者裁判。

当前均为公开有限实例/模拟回放。自检、基线与对照结果见各题目录及根 results/；更换随机种子不自动构成已经完成的泛化评测。
