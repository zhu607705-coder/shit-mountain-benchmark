# 推理赛道：两道开放策略优化题

| ID | 决策物 | 公开规模 | 自带基线原始分 | 简单对照原始分 |
|---|---|---|---:|---:|
| R1 | 任务选择、模式、依赖合法优先级 | 48 任务 / 24 情景 / 4 地区 | 212.870434383 | 92.357480971 |
| R2 | 按实验结果分支的干预决策树 | 18 实验 / 11 干预 / 180 世界 | 528.051477475 | 319.650920899 |

两题数据均为明确标注的合成数据，不预设最优解。评分项和硬约束固定，每个新解直接回放即可得到越大越好的 `raw_score`。比赛层再按当轮最好结果换算满分；这里不将自带基线伪装成满分。

每个子目录提供 `PROMPT.md`、`input.json`、`generate.py`、`baseline.py`、`judge.py`、实际运行的基线与简单对照 JSON，以及裁判自测。先读各题 README。`valid` 和 `feasible` 为同义字段；非法提交原始分为 0。

运行裁判时，务必使用组织者可信的 `judge.py` 和 `input.json`，仅将参赛方输出 JSON 作为 `--submission`。当前文件是公开演示包，未建立隐藏测试或远端沙箱。新轮次的封存 seed 与完整输入发放协议详见各题 README。
