# 自家基线：FIELD NOTES

`baseline.html` 为完全自包含、无外部依赖的页面。`baseline.template.html` 保留易读代码，`data.json` 是固定合成数据。使用绿色墨色与暖纸色，资源时间线和任务表共享同一状态，右侧展示任务详情；移动端保留可横向阅读的局部时间线，并提供完整表单与按钮。

## 已实现

- 12任务/4资源可视化，任务筛选、编辑、±15分钟改期。
- 左闭右开资源重叠与依赖结束时间检查；禁止未知依赖、自环、多节点环和工作窗口外编辑。
- 允许带约束问题的草稿持久保存，并持续显示问题清单；不自动改变任务计划。
- 最多50层本机快照撤销/重做，快捷键与按钮；刷新保留历史。
- 本机优先存储、离线切换、远端更新模拟器、字段级三方合并、显式选择冲突保留值。
- JSON导出包括本机、共同基线、模拟远端和冲突；存储失败可见。
- 跨窗口共享写入使用 Web Locks 串行化并在写前比较版本；有别页更新时暂停共享写入，保存独立恢复副本，提供导出或备份后显式载入共享版本。每次页面实例有独立恢复键，避免复制窗口共享 sessionStorage 标识造成互相覆盖。
- 原生dialog与表单、键盘替代拖拽、窄屏重排。

## 真实边界

- F10 采用显式、可恢复的拒绝覆盖路径；不会自动合并所有窗口的不同任务。共享版本改变后，本页仍可编辑独立副本，但必须导出或备份再载入共享版本；这是保守恢复行为。完整浏览器场景仍需独立验证。
- 无 Web Locks 时拒绝写共享账本，仅保存本页独立恢复副本并明确提示。普通刷新会优先恢复未提交草稿；显式“备份并载入共享版本”先存档当前副本，再读取共享版本。
- 远端是本机合成模拟器，没有真实服务器、鉴权、网络重试或CAS版本控制；离线开关控制此模拟状态，不声称浏览器断网检测。
- 合并/同步后清空撤销栈，避免旧快照跨版本撤销；此行为在完成消息里明确显示。
- 只允许编辑固定12任务，不支持新增/删除、真实日期跨日、拖拽、自动排程、导入JSON。
- 时间线对短任务只显示有限文字，完整名称在可访问label、表格和详情中；可访问与触屏体验需浏览器验证。
- 损坏的存储结构、跨设备共享、恢复草稿的完整历史管理仍不是完整实现；不主张生产可用。

## 基线评分的证据边界

`verification.json` 记录实际语法检查与公开函数自检。完整场景通过情况需要父级浏览器报告；`human_visual_score=null`，不能依据作者主观外观自给分。

只读调试入口 `window.BENCHMARK`：`tasks()`、`issues()`、`dirtyFields()`、`conflicts()`、`offline()`、`storageOK()`、`sharedWriteBlocked()`、`recoveryKey`、`whenSaved()`（保存队列完成 Promise）。正常操作通过UI完成，入口用于断言，不允许直接篡改状态替代测试。
