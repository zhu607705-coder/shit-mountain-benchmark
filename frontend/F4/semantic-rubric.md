# F4 语义评测映射

正式权重与资格门槛以统一比赛规则为准；本文件不另增隐藏门槛。任务看板、表格或时间线均可；字段和事件语义依据 PUBLIC_TASK.md。

| 公开任务 | 可复放断言 | 不应要求 |
|---|---|---|
| 不同字段合并 | 两个原生HTTP页面同时编辑同一任务的title与notes，刷新后两值都保留 | 固定`.task`或`#lane-2`结构 |
| 旧编辑器冲突 | 两页同时打开同一任务，一页保存同字段，另一页旧编辑器保存明确拒绝覆盖 | 固定错误字符串逐字相同 |
| 双页离线 | 两页离线分别改不同字段，顺序上线，重复消息不扩大事件数、不丢字段 | memory adapter替代真实Web Storage |
| 撤销保护 | 本页修改后，远端再次改相同字段；本页撤销不得覆盖远端 | 某个特定CRDT库 |
| 删除墓碑 | 删除确认后广播，另一页旧编辑器保存及更大clock迟到patch均不能复活 | 只检查当前页面卡片消失 |
| 导入安全与幂等 | 同文档重复导入；键序变化不算新内容；错误字段或同批ID异内容整批拒绝 | 未公开的类型容错规则 |
| 导出与恢复 | 浏览器真正下载完整JSON并独立重建；返回对象是独立快照 | 只检查点击下载按钮 |
| actor与存储 | 复制/opener窗口不能共享活动actor；损坏存储/配额失败反馈明确且保留可恢复状态 | 已在内存模拟通过就视作原生通过 |
| UI操作 | 表单提供拖拽等价的键盘路径；320/768/1440px、长文本、焦点保持分别检查 | 作者截图的像素答案 |

作者控件的语义示例：任务标题、工作站、开始时间、结束时间、备注；保存修改、重新载入、后移15分钟、删除任务、切换离线/恢复在线、撤销、重做、合并导入、导出、新建任务。其他等价命名应通过公开控件映射适配。

删除必须显式确认；具体可使用可访问HTML对话框或其他明确的二步确认。当前基线为适配本地in-app Browser改为HTML dialog，语义按钮为“取消删除”“确认删除任务”。原生confirm在本次surface中发生自动化超时，不能据此推断所有浏览器的confirm有问题。

当前实现的“跨窗口字段改写”提示表示历史中同字段出现不同actor的不同值，包含顺序改写，不能等同完整因果并发检测。高难档若要求精确因果识别，须另公布事件上下文协议。未执行的盲评、IME、长时负载和完整可访问性检查保持待测。
