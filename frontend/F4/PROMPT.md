# F4 · 两个窗口同时离线，排程被谁改没了？


## 参赛题面

修复并设计一个 local-first 排程工作室。任务包含标题、资源(workstation 0/1/2)、日内开始/结束分钟、备注。用户可拖动调整资源，也可用键盘完成同样操作；支持编辑、撤销/重做、导入/导出和多窗口协作。


## 基本语义

任务 ID稳定。不同字段的并发修改应合并；同一字段采用公开且确定的版本顺序，保留可见的冲突提示。允许用本任务给定的 Lamport时钟、actor、event_id 字典序作为顺序，也允许其他内部实现，只要导入导出语义一致。

编辑器从打开到保存之间，如果同一字段已经被其他窗口修改，保存必须提示冲突，不能静默覆盖。撤销只补偿本窗口的可逆修改，且不能覆盖之后的远端改动。删除为不可逆墓碑，确认后广播；迟到 patch 不得让删除对象重新出现。不同字段合并导致开始/结束不合法时，应明确显示冲突，不能凭空丢掉任务或默默修改时间。

离线编辑先在本窗口保留；恢复在线后合并，重复消息幂等。导入是 merge，不是覆盖现有文档。导出包含完整可重建状态。给定版本1 interchange 格式为 {version:1, events:[...]}; event 包含 id、actor、clock、item、kind(patch/delete)，patch另含 fields。资源与时间字段使用整数。标题及备注为文本。


## 关键情节

窗口A改标题，窗口B同时改备注；两个窗口都离线，分别修改后依次上线；A撤销旧命令时B刚完成新编辑；任务已删除但旧编辑器仍保存；拖拽后切换筛选；导入相同文件两次；同一字段真正冲突；编辑过程中缩成手机宽度。


## 高难档（未执行）

1,000 个任务、3–5窗口、50,000次混合操作、离线标签刷新/关闭恢复、输入法、长备注、导入错误数据和存储配额压力。错误不能静默吞掉，所有操作要有可理解反馈。允许不使用CRDT库，也不以是否使用CRDT作为评分条件。


## 前端质量

布局不仅需要好看，还必须解释“选中、正在编辑、未同步、冲突、删除”等状态；键盘流程可达，焦点不能被更新夺走。截图与交互共同评估。性能、工作流、可访问性和匿名设计质量分别公布。

## 本次适配补充公开契约（F4，2026-09-26）

本节是正式发布前的公开修订，适用于所有参赛者；本轮成绩以固定正式环境的实际结果为准。布局和技术栈继续开放。

- 提供 `window.bench.importDocument(document)` 与 `window.bench.exportDocument()`，仅用于注入/读取题面规定的事件文档。真实UI也应能导入导出。返回文档必须是独立快照，外部修改不能反向改变应用。
- 文档是 `{version:1,events:[...]}`。事件 `id/actor/item` 为非空字符串；`clock` 为0至9007199254740990的整数，`kind` 为 patch/delete。patch必须有非空 `fields` 对象，允许键仅为 `title/lane/start/end/notes`；title、notes为字符串，lane为0/1/2整数，start/end为0–1439整数。delete不带fields。资源字段的正式名称是 `lane`。
- 缺字段、错误类型、未知字段、同一导入批次或已有状态中同ID异内容，应整批拒绝，不能部分落入文档。对象键顺序不改变事件内容；相同消息重复导入幂等。禁止把字符串 `"1"` 当整数资源或把对象当标题。
- 同字段顺序按 clock→actor→id 比较；字符串按确定的 UTF-16码元字典序，不受浏览器locale影响。可以采用其他内部架构，但导入导出的最终状态应满足此公开顺序。不同字段独立合并；跨窗口字段改写至少有可见提示。仅凭Lamport顺序不能精确证明因果并发，不能把历史改写提示宣称为完整并发检测。
- 只有部分字段的新任务不可静默消失；可显示缺省字段与“时段不完整/冲突”状态。合并后start>=end时仍保留任务供人工修复。
- actor必须区分不同活动窗口；复制/由opener打开的窗口继承sessionStorage时，不能继续复用同一个活动actor。刷新可产生新actor，待同步旧事件须保留原actor与ID。
- 删除墓碑永久优先；更大clock的迟到patch也不能复活任务。编辑器保存前应重新确认远端删除；撤销不能覆盖后来的远端字段。撤销至少覆盖字段编辑；若新建不进入撤销栈，必须明示。删除不可撤销。
- 存储损坏不能悄悄作为合法事件导入；配额/权限失败必须可见并保留内存或恢复队列，不能宣称已同步。离线窗口关闭后的长期恢复仍属未计分高难档，若加入正式轮必须提前公布。
- 评测使用事件接口与可访问控件语义；不能要求作者的 `.task`、`#lane-2` 或内部DOM。

公开语义场景：两页不同字段修改→旧表单同字段冲突→双页离线编辑后上线→旧操作撤销保护→删除后的迟到消息→同文件重复导入→错误类型/同批ID冲突原子拒绝→真正导出文件与重载。窄屏、键盘替代拖拽、长文本和焦点保持独立评分。
