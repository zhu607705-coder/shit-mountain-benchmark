# 屎山 Bug 挑战赛 · 规则草案 v0.1

## 基本原则

没有唯一实现，也不预先知道全局最优方案；但是必须预先固定行为契约、允许信息、硬约束、损失定义、资源预算和评测方法。隐藏的是实例和故障组合，不是需求。可靠评分器仍需要可验证事实；“无需最优解”不能解释成“无需正确性定义”。

六个题目是六个任务族，不能把六次展示当成稳定的模型能力排名。参赛对象记录为“模型版本 + agent/harness + 可用工具 + 时间/调用预算”。采用独立目录和独立会话，不把前一模型的修改、报错、基线答案带给下一模型。

## 两层排行榜

先公布原始结果，再计算本轮相对分。对于有效作品 i，固定指标得到绝对质量 q_i，令 q_best 为本轮有效参赛作品和有效官方基线中的最大值。

S_i = 100 * q_i / q_best。

q_best 为 0 或没有合格作品时，本题无有效冠军，不把最不坏的违规作品封成满分。硬门槛不通过时竞赛分为 0，但保留诊断通过率。缺交题计 0，不能只平均提交过的题。

第一名的 100 是“本轮最好”，不是“理论最优”或“已经解决问题”。榜单冻结后新增模型应建立新版榜单；原始 q、loss 和通过情况始终可跨版本检查。固定质量分与相对竞赛分同时展示，避免一群差作品互相抬分。

## 建议质量函数

R1/R2 采用 q = 1 / (1 + L / c)，c 在赛前固定，v0.1 建议 c=10。L = 0.8 × 平均任务损失 + 0.2 × 最差 10% episode 的平均损失。这里是经验尾部均值，不声称已估计真实总体风险。错误但允许的判断通过任务损失处罚；越界操作、读取隐藏材料、修改评测器属于资格问题。

代码赛道先通过关键正确性契约，再采用 q = 0.5 × 扩展回归质量 + 0.3 × 性能质量 + 0.2 × 变形/迁移测试质量。每个测试族先汇总，再按固定权重组合；不能靠复制大量简单断言稀释一个丢数据错误。性能质量采用预先公布的截断对数映射，不使用参赛者自己上报的耗时、命中率或执行计数。

前端赛道建议 q = 0.60 × 用户工作流质量 + 0.15 × 无障碍/适配质量 + 0.10 × 性能质量 + 0.15 × 盲评设计质量。无障碍、响应式与性能各有独立实测。设计评分由匿名作品、统一内容和固定观察流程得到，不拿某个大模型的一句“界面精美”当权威评分。没有进行设计盲评时只公布已测分项，不补造总分。

性能质量、各测试族权重和盲评细则必须在正式开赛前锁定。仓库当前实现的是 smoke tests 和原始指标，不是以上全部正式评分器。

## 推荐赛事预算（设计值，非本次基线运行预算）

每题开发 90 分钟；4 vCPU / 8 GiB 开发环境；每个模型每题 3 个独立尝试，所有尝试均入统计。各题执行阶段另设时间、内存和工具调用上限。模型的生成花费单列，不混入应用运行性能。禁止事后挑最好一次冒充 pass@1。

主榜允许实现自由，统一依赖镜像和公开接口。推理赛道评估的是决策策略，可用标准 JSON 交互接口，也可提交 policy；代码语法和前端样式不在推理题内评分。这不是对“纯语言推理”能力的隔离测量。

## 高难度来自组合，而非歧义

公开基础需求和允许出现的扰动类型。开发后半程可发出第二阶段变更，但变更内容同一轮对所有模型相同。例子包括新故障组合、不同延迟分布、文件重命名、长文本、更新乱序和窗口断联。禁止临时增加未声明功能后用隐藏测试扣分。

扩展实例必须包含重复运行、边界条件、错误组合和与公开数据不同的场景结构。R1 的隐藏状态要能在公开概率模型下定义；无法区分的状态按剩余风险处理，不能要求模型凭空识别。R2 不给未来到达和故障种子。代码题同时检查修复效果与旧功能不回归。前端题检查真实用户操作，不只比较截图。

## 正式防作弊边界

participant.zip 不含基线、评分器、真值种子和测试结果。organizer.zip 只给出题者。隐藏评分器不能挂进参赛容器，即使挂成只读也会泄漏。正式部署需独立进程/容器验证、网络策略、资源上限、只读可信输入、无宿主凭据和文件访问审计。候选代码不应与评分器运行在同一个解释器。

本包 organizer/run_core.py 直接导入本包已知代码，用于作者自检，不是安全沙箱。不能据此直接运行不受信任的参赛作品。现有前端脚本也包含适配基线 DOM 的定位逻辑；正式自由布局评测应使用公开可访问名称、交互契约及独立结果校验，不锁定 baseline 的 class/DOM。

## 结果呈现

每题提供原始指标、有效性、固定质量分、本轮相对分、开发成本和主要失败类型。按实例簇计算不确定性，不将同一工程内的数千断言冒充数千独立样本。六个方向分项先展示，综合分仅作为辅助。难度须通过多种基线和独立模型试跑校准，不能预先承诺某个前沿模型一定低于 20 分。
